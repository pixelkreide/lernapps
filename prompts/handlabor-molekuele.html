Handlabor mit Handsteuerung

Moleküle per Hand drehen: Die Webcam erkennt die Hände, three.js zeichnet die 3D-Modelle, MediaPipe wertet die Gesten aus.

App starten ▸

So nutzt du ihn: Öffne einen neuen Chat mit Claude und füge den Prompt ein. Dein Ergebnis kann von der App hier abweichen.

Erstelle eine eindrucksvolle Lern-App „Handlabor“ für den Chemieunterricht als eine einzige HTML-Datei. Die Lernenden drehen und vergrößern 3D-Molekülmodelle mit bloßen Händen vor der Kamera.

BIBLIOTHEKEN
- Wenn du Code ausführen kannst: Bette three.js und MediaPipe Hands samt Modelldateien in die Datei ein, damit sie komplett offline läuft.
- Wenn nicht, nutze genau diese Versionen per CDN und die globalen Objekte THREE und Hands, keine ES-Module:
  https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js
  https://cdn.jsdelivr.net/npm/@mediapipe/hands@0.4.1675469240/hands.js
  Lade die Modelldateien mit: locateFile: f => `https://cdn.jsdelivr.net/npm/@mediapipe/hands@0.4.1675469240/${f}`

INHALT
- Modelle: DNA-Doppelhelix, Fußball-Molekül C60, Kochsalz-Gitter und Diamant
- Atome als Kugeln in den üblichen Elementfarben, Bindungen als Stäbe
- Oben rechts Kacheln für die Modelle
- Rechts eine helle Seitenleiste mit den Reitern Steuern, Modell und Aufträge
- Vier Prognose-Aufträge: erst vermuten, dann am Modell prüfen, mit Rückmeldung

HANDSTEUERUNG
- Kamera erst nach Klick auf „Handsteuerung starten“ einschalten
- Kleines gespiegeltes Kamerabild, leuchtendes Handskelett über dem Modell
- Hands-Optionen: maxNumHands 2, modelComplexity 0
- Daumen und Zeigefinger zusammen: greifen und drehen, das Modell dreht nach dem Loslassen sanft aus
- Beide Hände greifen: auseinanderziehen vergrößert, kippen dreht zur Seite
- Zeigefinger: auf ein Atom zeigen nennt seinen Namen, eine Sekunde auf einer Kachel wechselt das Modell
- Offene Hand: bremst die Drehung
- Griff im Verhältnis zur Handgröße messen, damit er auch mit Abstand zur Kamera funktioniert. Zum Lösen eine größere Schwelle verwenden als zum Greifen, damit nichts flackert. Handpositionen glätten.
- Aktuelle Geste als Text anzeigen

WEITERE ANFORDERUNGEN
- Ohne Kamera vollständig mit Maus und Touch bedienbar
- Verständliche Fehlermeldung, wenn die Kamera blockiert ist oder das Modell nicht lädt
- Kurzer Hinweis: Das Kamerabild wird nur im Browser ausgewertet, nichts wird gespeichert oder gesendet
- Oberfläche auf Deutsch, auch am Handy bedienbar

Gib die komplette Datei ohne Auslassungen und ohne Platzhalter aus. Prüfe den Code vorher auf Fehler und nenne in drei Sätzen, was ich testen soll.
