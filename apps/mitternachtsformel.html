Die Mitternachtsformel

Quadratische Gleichungen Schritt für Schritt lösen

Was weißt du noch?

Löse die drei Aufgaben im Kopf, bevor du weitermachst. So merkst du, was du schon kannst.

Worum geht es?

Eine quadratische Gleichung hat die Form a·x² + b·x + c = 0 mit a ≠ 0. Ihre Lösungen sind die Stellen, an denen die Parabel y = a·x² + b·x + c die x-Achse schneidet.

Die Mitternachtsformel funktioniert für jede solche Gleichung. Der Name kommt von der Redewendung, man müsse sie auch dann aufsagen können, wenn man um Mitternacht geweckt wird.

Selbst lösen

Bestimme die Lösungsmenge. Jede Zwischenstufe wird geprüft. Hilfe gibt es nur, wenn du sie brauchst.

Entdecke

1. Stelle c so ein, dass die Parabel die x-Achse gerade noch berührt. Wie groß ist D?

2. Erkläre: Warum gibt es für D < 0 keine Lösung?

Mit Musterantwort vergleichenUnter der Wurzel steht dann eine negative Zahl. Keine reelle Zahl ergibt quadriert etwas Negatives. Die Parabel schneidet die x-Achse nicht.

3. Begründe: Warum bleibt für D = 0 nur eine Lösung übrig?

Mit Musterantwort vergleichenDann steht in der Formel ± 0. Plus und minus ergeben denselben Wert. Die Parabel berührt die x-Achse in ihrem Scheitel.

Deine Checkliste

  1. Bringe die Gleichung in die Form a·x² + b·x + c = 0.
  2. Lies a, b und c mit Vorzeichen ab.
  3. Schreibe die Formel auf und setze mit Klammern ein.
  4. Berechne die Diskriminante D = b² − 4ac.
  5. Entscheide: D > 0 zwei Lösungen, D = 0 eine Lösung, D < 0 keine Lösung.
  6. Rechne x₁ mit Plus und x₂ mit Minus aus.
  7. Notiere die Lösungsmenge und mache die Probe.
